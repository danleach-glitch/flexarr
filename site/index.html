Install

Up and running in five minutes.

Flexarr runs on anything with Docker: a NAS, a home server, a Raspberry Pi 5. On a Mac it runs natively, so it can use the Mac's hardware for converting video.

Start the server

docker run -d --name flexarr --restart unless-stopped \
  -p 8383:8383 \
  -v /path/to/config:/config \
  -v /path/to/media:/data/media \
  ghcr.io/danleach-glitch/flexarr:latest
services:
  flexarr:
    image: ghcr.io/danleach-glitch/flexarr:latest
    container_name: flexarr
    ports: ["8383:8383"]
    volumes:
      - ./flexarr:/config
      - /path/to/media:/data/media
    restart: unless-stopped

Save it as docker-compose.yml and run docker compose up -d.

Flexarr runs on macOS (Apple silicon or Intel) as a background service that starts when you log in, using VideoToolbox to convert video in hardware. Follow the macOS guide.

Mount your media at the same path Sonarr and Radarr use, so the paths they report match what Flexarr sees (or map them in Settings › Connections). latest is always the newest release.

Sign in

Open http://<your-server>:8383 in a browser. On first run Flexarr makes an API key and saves it in config.json in its config folder. Sign in with it once; after that each browser and device gets a sign-in of its own.

docker exec flexarr cat /config/config.json

Add your libraries and *arr apps

In Settings › Libraries, add your film, TV and music folders. In Settings › Connections, add Sonarr and Radarr with their API keys. Then, in each app, add a Webhook connection (Settings › Connect) with the address shown in Flexarr's Settings › Server, so new downloads appear straight away.
