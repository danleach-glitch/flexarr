Your own cinema.

Flexarr is a free, open-source media server for your films, TV and music. It sits alongside Sonarr, Radarr and Lidarr, streams to your browser, Apple TV, iPhone and iPad, and needs no account and no cloud.

What it does

Everything Plex does. Plus the bits it doesn't.

Flexarr reads artwork, descriptions and cast straight from your Sonarr and Radarr, so there are no other accounts or API keys to set up. New downloads appear the moment they import.

Made for the *arr stack

Sonarr, Radarr, Lidarr and Seerr are first-class neighbours: webhooks, Coming soon, requests, fixing a match and finding a better copy all go through them.

Plays anywhere

Direct play when the device can, otherwise conversion as you watch with hardware acceleration, HDR to SDR, subtitles and seeking anywhere instantly.

Skips the boring bits

Intros, recaps and credits are found by listening across each season, so Skip Intro and Up Next just work, even for shows Plex never marked.

For the whole household

Profiles with their own Continue Watching and history, optional PINs, and libraries each person can see. Every browser and TV signs in on its own.

Away from home, safely

Watch over Tailscale with no ports opened on your router. On your own network, devices find the server by themselves.

Bring your Plex history

Watched state and resume points come over from Plex, matched by file, without touching Plex. Library health spots duplicates and poor copies too.

On iPhone and iPad: Picture in Picture, AirPlay, Skip Intro and Up Next.

Install

Up and running in five minutes.

Flexarr runs on anything with Docker: a NAS, a home server, a Raspberry Pi 5. On a Mac it runs natively, so it can use the Mac's hardware for converting video.

Start the server

docker run -d --name flexarr --restart unless-stopped \
  -p 8383:8383 \
  -v /path/to/config:/config \
  -v /path/to/media:/data/media \
  ghcr.io/danleach-glitch/flexarr:latest
services:
  flexarr:
    image: ghcr.io/danleach-glitch/flexarr:latest
    container_name: flexarr
    ports: ["8383:8383"]
    volumes:
      - ./flexarr:/config
      - /path/to/media:/data/media
    restart: unless-stopped

Save it as docker-compose.yml and run docker compose up -d.

Flexarr runs on macOS (Apple silicon or Intel) as a background service that starts when you log in, using VideoToolbox to convert video in hardware. Follow the macOS guide.

Mount your media at the same path Sonarr and Radarr use, so the paths they report match what Flexarr sees (or map them in Settings › Connections). latest is always the newest release.

Sign in

Open http://<your-server>:8383 in a browser. On first run Flexarr makes an API key and saves it in config.json in its config folder. Sign in with it once; after that each browser and device gets a sign-in of its own.

docker exec flexarr cat /config/config.json

Add your libraries and *arr apps

In Settings › Libraries, add your film, TV and music folders. In Settings › Connections, add Sonarr and Radarr with their API keys. Then, in each app, add a Webhook connection (Settings › Connect) with the address shown in Flexarr's Settings › Server, so new downloads appear straight away.
