# Security Policy

Flexarr is a self-hosted server that is often exposed to the internet, so we take security reports seriously.

## Reporting a vulnerability

**Please do not open a public issue.** Report vulnerabilities privately via GitHub's
[private vulnerability reporting](https://github.com/danleach-glitch/flexarr/security/advisories/new).

Include the affected version, steps to reproduce and the impact. We aim to acknowledge reports within 72 hours.

## Supported versions

Flexarr is pre-1.0; only the latest release and `main` receive security fixes.
